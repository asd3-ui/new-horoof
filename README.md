# حروفي المرحة 🌈

تطبيق تعليمي عربي تفاعلي للأطفال (3–8 سنوات) لتعلّم الحروف العربية والكلمات والأرقام والأشكال، من خلال **15 نشاطًا** وألعاب ممتعة، مع نطق عربي، ومكافآت، ومتابعة تقدّم للوالدين.

> الإصدار 2.0.1 — إعادة بناء كاملة بواجهة متجاوبة مع جميع الهواتف.

---

## ✨ المميزات

### تعلّم الحروف
- **28 حرفًا عربيًا** مع اسم الحرف وصوته.
- **3 أمثلة لكل حرف** (84 كلمة وصورة تعبيرية).
- **أشكال الحرف الأربعة**: منفرد، أول الكلمة، وسطها، آخرها.
- بطاقة حرف مفصّلة مع تلميح تعليمي ونطق صوتي.
- تتبّع الحروف واستكشافها، وإضافة الحرف تلقائيًا إلى قائمة «تعلّمت».

### التحفيز والمكافآت
- **نجوم** تُجمع من كل نشاط.
- **6 مستويات** من «مغامر صغير» إلى «أسطورة الحروف».
- **14 شارة إنجاز** و**12 ملصقًا** في ألبوم الملصقات.
- **شهادة إنجاز** تُفتح بعد 25 نجمة أو استكشاف 20 حرفًا.
- **تحدي اليوم** يتغيّر تلقائيًا كل يوم.
- **سلسلة الأيام (Streak)** لتشجيع المثابرة.

### للوالدين والمعلمين
- لوحة متابعة: النجوم، الحروف المكتسبة، الأيام المتتالية.
- تقدم كل نشاط وأفضل نتيجة.
- خريطة الحروف الـ28 (مكتسب/غير مكتسب).
- إعدادات الصوت والاهتزاز والاحتفالات.
- نصائح تربوية، وإعادة ضبط التقدم.

## 📱 التوافق مع جميع الهواتف

- تصميم **متجاوب بالكامل** يعتمد على `useWindowDimensions` بدلًا من المقاسات الثابتة.
- يعمل على الشاشات الصغيرة (320px) والمتوسطة والكبيرة والأجهزة اللوحية.
- **مناطق آمنة** (Safe Area) أعلى وأسفل الشاشة، مع دعم الوضع edge-to-edge في Android.
- **أزرار بمساحة لمس مريحة** (معظمها ≥ 44px) مناسبة لأصابع الأطفال.
- **حدّ لتكبير الخط** يمنع كسر التصميم عند تغيير إعدادات خط النظام.
- شبكات وصفوف مرنة (`flexWrap`) تمنع خروج المحتوى عن الشاشة.
- دعم كامل للكتابة من اليمين إلى اليسار.
- زر الرجوع في Android يعمل بشكل صحيح في كل الشاشات.
- يعمل دون اتصال بالإنترنت؛ المؤثرات الصوتية مضمنة داخل التطبيق، والنطق يعتمد على أصوات TTS المثبتة على الجهاز.

## 🧰 التقنية

- **React Native 0.81** + **Expo SDK 54** (New Architecture).
- **expo-speech** للنطق العربي (يعتمد على أصوات الجهاز).
- **expo-av** للمؤثرات الصوتية القصيرة.
- **react-native-svg** لرسم الأشكال الهندسية ولوحة الرسم.
- **AsyncStorage** لحفظ التقدم محليًا.
- واجهة عربية RTL، بدون أي مكتبات واجهة خارجية.

## 🚀 التشغيل

```bash
npm install
npx expo start
```

- امسح رمز QR بتطبيق **Expo Go** المتوافق مع SDK 54.
- أو شغّل على محاكي Android:

```bash
npm run android
```

> **ملاحظة:** ملف `package-lock.json` مكتمل ومثبّت. في CI استخدم `npm ci` لتثبيت نفس الإصدارات بالضبط.

## 🔨 بناء APK

### محليًا
```bash
npx expo install --check
npx expo prebuild --platform android
cd android
./gradlew assembleRelease
```

### عبر GitHub Actions
سير العمل `.github/workflows/android-apk.yml` يبني APK تلقائيًا عند الدفع إلى `main`، ويرفع الناتج كـ Artifact.

## 🗣️ ملاحظات حول النطق

- جودة النطق تعتمد على محرك **TTS** والأصوات العربية المثبّتة على الجهاز.
- على Android: الإعدادات ← النظام ← اللغات والإدخال ← تحويل النص إلى كلام ← تثبيت صوت عربي.
- إذا لم يتوفر صوت عربي، يستخدم التطبيق الصوت الافتراضي دون توقف.
- زر «اختبار الصوت» في لوحة الوالدين يساعد على التحقق من النطق.
- **إصلاح 2.0.1:** لا يستدعي التطبيق `getAvailableVoicesAsync` بعد الآن. في بعض إصدارات `expo-speech` يوجد خطأ أصلي (`NullPointerException` داخل `LanguageUtils`) عند تعداد أصوات محركات TTS على بعض أجهزة أندرويد، وكان يسبب إغلاق التطبيق فور أول نطق. الآن يُمرَّر `language: "ar-SA"` مباشرة ويختار النظام الصوت العربي الأنسب بأمان.

## 🔒 الخصوصية

- جميع البيانات (الاسم، النجوم، التقدم) تُحفظ **محليًا على الجهاز** فقط.
- لا يوجد تسجيل دخول، ولا إعلانات، ولا تتبّع، ولا إرسال بيانات.
- يمكن حذف تقدم الطفل والنجوم والمكافآت من «لوحة الوالدين ← إعادة ضبط كل التقدم».

## 🆕 ما الجديد في الإصدار 2.0.1

- إصلاح إغلاق التطبيق فور الضغط على «ابدأ اللعب» أو أول نطق (خطأ TTS الأصلي على أندرويد).
- إضافة حاجز أخطاء (Error Boundary) يعرض رسالة لطيفة بدل إغلاق التطبيق عند أي خطأ غير متوقع.
- تحسين التوافق مع محركات النطق المختلفة بإزالة تعداد الأصوات غير الآمن.

## 🆕 ما الجديد في الإصدار 2.0

- إعادة بناء كاملة إلى وحدات منظمة بدلًا من ملف واحد.

- أشكال الحروف الأربعة داخل صفحة الحرف.
- 10 أشكال هندسية قابلة للتلوين والرسم.
- نظام مستويات وشارات وملصقات وشهادة إنجاز موسّع.
- تصميم متجاوب وآمن لجميع الهواتف، مع دعم الأجهزة اللوحية.
- تحسينات أداء: تخزين مؤقت للأصوات، تقليل إعادة الرسم، وتنظيف المؤقتات.

- دعم زر الرجوع في Android وإعدادات الصوت والاهتزاز.
